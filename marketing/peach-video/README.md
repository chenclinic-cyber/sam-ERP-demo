# 🍑 水蜜桃醫美影片素材包

**主題**：除毛雷射 × 私密緊緻（Peach Fuzz → Silky Smooth）
**規格**：20 秒｜9:16 直式（IG Reels / TikTok）

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `peach_animatic_720x1280.mp4` | 動態分鏡草稿（animatic），含配樂與蛻變「叮」音效，供團隊確認節奏與構圖 |
| `prompts_copy_paste.txt` | 五個分鏡的 AI 生成 Prompt（已合併角色設定），可直接貼入 Kling / Hailuo / Veo / Runway |
| `render_animatic.py` | 動態草稿渲染程式（Python + Pillow + ffmpeg），改字卡或時間軸後可重新輸出 |

## 正式成片製作流程

1. 用 `prompts_copy_paste.txt` 最後的定裝照 Prompt 在 Midjourney / 即夢生成角色定裝照
2. 每個分鏡用同一張定裝照做 image-to-video（一致性遠高於純文字生成）
3. Shot 3 左右對比鏡是記憶點，多抽幾次卡挑對比最明顯的版本
4. 配樂：spa lounge / luxury pop，蛻變瞬間加「叮」音效（animatic 內已示範時間點：第 10 秒）
5. 片尾加診所 logo 與文案「換一層肌，換一種自信」

## 法規提醒（台灣，醫療法 85/86 條）

- 避免保證療效字眼（「一次見效」「永久光滑」）
- 標註療程名稱時加「療程效果因人而異」聲明（animatic 字卡已內建）
